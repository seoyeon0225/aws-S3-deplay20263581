# 🐾 멍냥마켓 (Pet Shop Landing Page)

반려동물 용품(강아지/고양이) 쇼핑몰의 프론트엔드 UI를 구현한 프로젝트입니다. 

## 💡 주요 기능
- **반응형 웹 디자인:** 모바일, 태블릿, PC 등 다양한 화면 크기에 맞춰 자연스럽게 변환됩니다.
- **동적 필터링 기능:** 전체보기, 강아지, 고양이 탭을 클릭하여 카테고리별로 상품을 바로 확인할 수 있습니다.
- **직관적인 UI:** 사용자 친화적이고 깔끔한 쇼핑몰 인터페이스를 제공합니다.

## 🛠 사용된 기술 (Tech Stack)
- HTML5
- Tailwind CSS (스타일링 및 반응형 레이아웃)
- Vanilla JavaScript (DOM 제어 및 필터링 기능)
